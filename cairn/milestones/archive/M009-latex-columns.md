# M009: Keep LaTeX column layouts intact

**Status:** done (2026-10-26, PR #9 https://github.com/jmgirard/wrapped/pull/9)

**Goal:** In PDF through LaTeX, wrapped figures leave the document's column layout as the document sets it up.

**Outcome:** `wrapped.tex` checks at each `wrappedfigure` start whether the text runs in columns: a flag set by `\AddToHook{env/multicols/begin}` (and `multicols*`), tested first, then `\if@twocolumn` (set by a class default, `\twocolumn`, and paracol). It then picks a mode: w calls wrapfig as before; f puts a captioned figure in a `figure` float in two-column text; p sets the figure in place in a centered `minipage` with `\@captype` figure and `hypcap=false`, inside `multicols`, or in two-column text inside a box (`\mode_if_inner_p:`) or with no caption. Each fallback has the `width` key's width and writes a LaTeX log warning: once per run for two-column text, once per figure in `multicols`. `wrapped.lua` adds `caption=false` to an uncaptioned image's raw environment; its `classoption` check and console warning are unchanged. The gap is kept in `\wrapped@gap` and set as a local `\columnsep` at the start of wrapfig's `\WF@putfigmaybe`, replacing the global set and restore, so a local `\columnsep` around a figure no longer leaks. Tests: fixtures `twocolumn-class` (with `tests/twocol.cls`), `twocolumn-switch`, `multicols`; layout cases for no text beside, in-place order, image width as 0.4 of its column or box, column gap, and a 30pt wrap-gap; a `LOGS` check that reads each `.log` (`latex-clean: false`, rendered with `max_print_line=79`) for the warnings and no caption hypcap warning. 39 renders on macOS and in CI. README, DESIGN, PROFILE, and wrap-mechanisms W2 updated.

**Decisions:** none milestone-local. Plan choices in the work log: a TeX-side check over a Lua list of two-column classes; a local `\columnsep` in `\WF@putfigmaybe`; a test class file over an IEEEtran dependency. AC6 amended at the user's stop (paracol is detected).
