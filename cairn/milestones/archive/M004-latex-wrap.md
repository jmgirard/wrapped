# M004: Wrap figures in LaTeX PDF output

**Status:** done (2026-10-25, PR #4 https://github.com/jmgirard/wrapped/pull/4)

**Goal:** A document rendered to PDF through LaTeX with the extension installed shows body text beside each figure marked `.wrap-left` or `.wrap-right`.

**Outcome:** `_extensions/wrapped/wrapped.tex` defines `wrappedfigure` (keys `side`, `width`, `gap`, `lines`) over wrapfig's floating placements R and L, so a figure that does not fit moves to a paragraph on the next page. It sets `\columnsep` to the gap at its end and restores it from hooks on `\WF@startwrapping` and `\WFclear`. It ends an earlier wrap that is still narrowed before a new figure, puts out a waiting figure centered (a redefined `\WFclear`), places a waiting figure only on the group level where it ended (no headings or callout ends), and sets captions plain and ragged-right. `wrapped.lua` sets `fig-env`/`fig-pos` on wrapped floats and captioned images, wraps an uncaptioned image in a raw `wrappedfigure` with `fig-alt` as its alt text, converts lengths (percent to `\linewidth`, px to pt at 0.75, TeX units as written, others to the default with a warning), checks `wrap-lines`, keeps an image's height, and falls back with one warning when `classoption` turns on twocolumn. Context and unplaced-image warnings now print in LaTeX. Tests: fixtures `twocolumn`, `twocolumn-list`, `pdf-ua` (ua-2, article), `pdf-ua1`, `tex-options`, and PDF renders of `fixture`, `defaults`, `contexts`, `stop-rule` in `tests/verify.py` (22 renders); the `.tex` snapshot records each environment's and image's options. README gains a "PDF through LaTeX" section with wrapfig's limits.

**Decisions:** none milestone-local. Implement choices are in the work log: the gap through a global `\columnsep` with a restore hook, floating placements, ending an earlier wrap with skipped lines, and the group-level placement guard (replacing an `\@hangfrom` patch).
