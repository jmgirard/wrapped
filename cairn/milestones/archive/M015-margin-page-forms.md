# M015: Fall back in more margin and page forms

**Status:** done (2026-10-27, PR #15 https://github.com/jmgirard/wrapped/pull/15)

**Goal:** A wrapped figure whose caption a `.margin-caption` or `.caption-margin` class sends to the margin of an HTML page, or that a document-level `fig-column` or `column` key puts in the margin or a page-wide column, keeps its normal layout with one warning, in the formats where M013's forms of the same place do.

**Outcome:** `margin_caption_class` makes `caption_location` read both classes on a float or its image, and `figure_block` reads `.margin-caption` alone on a captioned image with no id (HTML pages only). A code cell's `.margin-caption` is carried to its float (`carry.margin_caption`); Quarto turns a cell's `caption-margin` into `cap-location` itself. `read_meta` reads the document's `fig-column`, else `column`, through `meta_column` (empty is unset, a list gives its first item), into `meta_column_context`, a cell context and a float context that the float pass checks after the class and panel checks. `page_context` now covers Typst: all 16 page-wide names for a div or cell, and for a float's own class (`own`) only `column-page` and `column-screen` without `-inset`. Fixtures: new margin-meta, page-wide-meta, column-meta, typst-inset-meta; new cases in cap-margin, page-wide, revealjs (87 renders). README "Where a figure keeps its normal layout", DESIGN steps 2 and 4, and E3, E20, E21 updated.

**Decisions:** none milestone-local. The question set chose this row over dashboards. Two substantive amendments followed renders without the extension: AC1, AC3 to AC5 match Quarto 1.10.19 (a cell's `fig-column: body` does not keep its float in the body under a document key; a no-id image moves its caption only for `.margin-caption`), and AC4 makes Typst page-wide floats fall back, which the user chose at a stop after the claim audit found them overlapping the text (since M013).
