# M006: Wrap figures in Word output with frames

**Status:** done (2026-10-26, PR #6 https://github.com/jmgirard/wrapped/pull/6)

**Goal:** A document rendered to Word with the extension installed shows body text beside each figure marked `.wrap-left` or `.wrap-right`, in Word.

**Outcome:** A second filter entry, `wrapped-docx.lua` at `post-render`. `wrapped.lua` groups each docx figure as in HTML and marks the `.wrap-group` with `data-wrap-frame` (side, width, gap in twips); the post-render pass removes Quarto's one-cell figure table, turns a Pandoc `Figure` into image and `ImageCaption` paragraphs, and puts the same `w:framePr` (`w:wrap="around"`, `w:hAnchor="margin"`) in a raw `w:pPr` after Pandoc's and Quarto's own on every paragraph of the figure (image paragraphs keep Compact or CaptionedFigure); a `<w:br w:type="textWrapping" w:clear="all"/>` ends the group's last paragraph. Word 16 reads the frame and the last pStyle from those later `w:pPr` (T1). Widths: a percent of the reference doc's body `w:sectPr` text width (page less margins and gutter, via `PANDOC_WRITER_OPTIONS.reference_doc` and `pandoc.zip`), or 9360 twips when it has no page size or margins; in/cm/mm/pt/pc at 1440 twips per inch, px at 15, em at 240; 0%, other units, and widths at or above the text width take the default with a warning; images take the frame width, heights drop with a warning. A reference doc with columns keeps normal figures with one warning; a figure holding a code block, table, heading, rule, or raw block keeps its layout with a warning. Tests: docx renders of fixture, defaults, stop-rule, contexts, docx-reference, docx-options, docx-columns (35 renders); the docx summary records each frame, its members, links, citations, and blocks to the clearing break; `tests/reference_narrow.py` writes the reference docs; `tests/word-pdf.applescript` exports through Word. README Word section: Word 16.114 and LibreOffice 26.8 show text beside all 15 fixture figures; Google Docs shows the figure on its own lines (user's look, first figure).

**Decisions:** none milestone-local. D-005 (LibreOffice as a check tool) was added at plan. One amendment: AC5 counts a Word height warning (user's wording at a stop, after two re-audits).
