# M039: Wrap table floats in Word

**Status:** done (2026-10-31, PR #41 https://github.com/jmgirard/wrapped/pull/41)

**Goal:** A `#tbl-` table float with a wrap class wraps the paragraphs after it in Word, in a floating table that holds its caption.

**Outcome:** `wrapped.lua`'s `float_target` lets a table float wrap in Word through `docx_frame`; the table warning covers LaTeX only and reads "A table wraps in HTML, Typst, and Word." A table float whose table is raw openxml (`raw_docx_table`, as gt and flextable write) keeps its normal layout in Word with a warning. `docx_size(..., by_column)` fits a table float's images: one outside its table fills the box, and one in a cell takes at most its cell's share (`column_shares`, matching `fit_table`, summed over a column span, less 216 twips, floor half the cell), keeping a smaller own width. `clean_images` gives a table image its own height-warning sentence; the figure sentence keeps the user's M006 wording. In `wrapped-docx.lua`, `float_div` finds a `tbl-` float table and `floating_table` replaces it with a raw `w:tbl` open tag (`w:tblpPr` with the side and the gap toward the text, zero cell margins), the float div, and a raw close tag, which Pandoc 3.10 writes as they are. A 1 pt `w:keepNext` paragraph goes before the box, so a table before it does not join it and a heading stays with it; `fit_table` gives the inner table relative widths; the cell gets a closing paragraph unless its last block writes one. `tests/verify.py`'s `docx_tables` lists each floating table (side, width, text distances, anchors, the block before, cell parts, cell image widths, after-blocks, links, citations), with `docx_after` shared with frames. New fixture `tests/docx-tables.qmd` (Word only); `tables-column-meta` renders to Word. Site pages, README, DESIGN.md, and `references/wrap-mechanisms.md` say tables wrap in Word, with the gt and flextable exception.

**Decisions:** D-022 (table floats wrap in Word as floating tables; supersedes part of D-021), D-023 (raw Word XML table floats keep their normal layout; narrows D-022). Milestone-local: none.
