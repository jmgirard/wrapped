# M040: Wrap table floats in LaTeX PDFs

**Status:** done (2026-10-31, PR #42 https://github.com/jmgirard/wrapped/pull/42)

**Goal:** A `#tbl-` table float with a wrap class wraps the paragraphs after it in PDF through LaTeX, as it does in HTML, Typst, and Word.

**Outcome:** `wrapped.lua`'s `float_target` gives a LaTeX table float `fig-env` `wrappedtable` and its `tex_options` in `tbl-pos`, which Quarto reads for a table float that holds no longtable (Quarto 1.9.36 and 1.10.20). `latex_tabular` rewrites each Pandoc table in it as a `tabular`: shares from a `tbl-colwidths` list on the table or its float (`table_colwidths`, Quarto's rounding and no-span rule), else `text_shares` (each column's longest cell text when no column has a width, skipping row-span-covered columns, else `column_shares`); `pandoc.write`, the `\LTcaptype` group dropped, the first head kept, the foot after the body, `multirow` loaded when used. Each cell is written as a token, and its own inlines (one paragraph) or blocks (in a minipage) are spliced back between raw pieces, so Quarto resolves shortcodes, cross-references, and citations and the main writer loads soul and highlighting. A float that holds raw LaTeX keeps its normal layout with a warning (`raw_latex_table`). `wrapped.tex` builds `wrappedfigure` and `wrappedtable` on shared `\__wrapped_begin:nn`/`\__wrapped_end:n` (modes w, f, p), names the kind in the multicols warning and tables in the two-column one, and keeps a wrappedtable's footnote text for after the environment (`\makesavenoteenv` groups it and stops the wrap). Tests: LaTeX `LAYOUT` cases for `tables` (five forms, stop), new fixtures `tables-latex`, `tables-span` (+ `html-table.lua`), `tables-cells` (+ `cells.bib`), `tables-cap-margin` to PDF, tables in `multicols` and `twocolumn-switch`; `tex_summary` lists each `wrappedtable` and its column factors. Docs, README, DESIGN (goals, non-goals, steps 4 and 7, a LaTeX Known issues entry), and wrap-mechanisms W2 and E5 updated.

**Decisions:** D-024 (table floats wrap in LaTeX as tabulars; supersedes part of D-021 and D-022). Milestone-local: none. One substantive amendment: AC2's column shares from equal to each column's longest cell text, at the user's choice.
