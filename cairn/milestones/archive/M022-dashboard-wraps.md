# M022: Wrap figures in dashboard cards

**Status:** done (2026-10-28, PR #24 https://github.com/jmgirard/wrapped/pull/24)

**Goal:** In a Quarto dashboard, a wrapped code-cell figure inside a `.card` div wraps the text after it in that card, and a wrapped code-cell figure outside a `.card` div keeps its normal layout with a warning.

**Outcome:** `wrapped.css` sets `.wrap-group .cell.html-fill-container` and `.wrap-group .cell-output-display.html-fill-container` to `display: block`, so a cell figure's float reaches the paragraphs after the cell, and `.wrap-group.html-fill-item` to `flex: 0 0 auto`, so a card that fills its height does not shrink the group under the next block. These win over Bootstrap's fill rules by load order. In `wrapped.lua`, `is_dashboard` and a `card_depth` count in `find_contexts` make a code cell outside a `.card` div the context "is outside a card in a dashboard" (D-013); a `.card` div that is itself a context (`layout-ncol`, tabset, `.columns`) keeps it. Markdown figures and images already wrapped in cards. `tests/layout.js` `nextBlock` stops at the group's `.card-body`. Fixture `tests/dashboard.qmd` (7 cases) with a `dashboard` render and snapshot. README "Dashboards" section and list item, DESIGN.md steps 2 and 5, PROFILE.md verify slot, and `wrap-mechanisms.md` W1 and E8 updated.

**Decisions:** none milestone-local. Promoted D-013 (the outside-card fallback, the user's answer at the M021 plan). Plan choices: CSS scoped to `html-fill-*` classes; no auto-made card around a bare cell.
