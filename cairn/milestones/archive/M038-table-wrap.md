# M038: Wrap table floats in HTML and Typst

**Status:** done (2026-10-30, PR #40 https://github.com/jmgirard/wrapped/pull/40)

**Goal:** A `#tbl-` table float with a wrap class wraps the paragraphs after it in HTML and in PDF through Typst, and keeps its normal layout with a warning in PDF through LaTeX, Word, and EPUB.

**Outcome:** In `wrapped.lua`, `float_target` lets a table float wrap in HTML and Typst, taking its class from the float, its code cell, or its caption block (`drop_caption_wrap`); in LaTeX and Word every wrapped table float keeps its normal layout with "the table #<id> does not wrap in LaTeX/Word. A table wraps only in HTML and Typst.", before the next-block rule; `found_wrap` is set for figure and table floats only, so EPUB prints its format warning. `caption_in_margin` reads `tbl-cap-location` for tables. Column classes are scoped by float type: `block_context` reads all of a cell's classes (margin first), then returns a scope and the plain context of its other classes; `scoped_context` holds a `fig-column-*` or `tbl-column-*` context for floats of that type only, and the walk goes on into such a cell so subfigure panels are still recorded; `column_context` reads `tbl-column` for tables and drops the other type's scoped classes (`own_type_classes`); `read_meta` keeps the document's `tbl-column` apart. A table float reads the column class Quarto moves onto the `cell-output-display` div inside it, in every format. `cell_div` anchors a group for a cell with a wrap class or a table float. `wrapped.css` lets a table wider than its box scroll inside it; in Typst the columns narrow (DESIGN.md Known issues). Tests: `tests/tables.qmd` (five forms, no-text, callout, margin, page-wide, wide table) in HTML, Typst, LaTeX, Word, and EPUB, with Typst beside cases (`typst_table_case`) and a `layout.js` `tableInside` check; `tables-cap-margin`, `tables-cap-margin-meta`, `tables-column-meta`, `tables-fig-column-meta`, `tables-cell-columns`, and `tables-column-body`. The site gained "Wrap a table" on Get started and table rules on the normal-layout, reference, stopping, index, and four format pages, and the README.
