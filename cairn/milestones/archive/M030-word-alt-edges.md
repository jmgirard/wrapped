# M030: Fix the Word alt text edge cases

**Status:** done (2026-10-29, PR #32 https://github.com/jmgirard/wrapped/pull/32)

**Goal:** In Word output, a framed div float that holds more than one image gives its `fig-alt` text to no image but its first, and every framed image's alt text keeps the repeated spaces of its `fig-alt`.

**Outcome:** In `wrapped-docx.lua`, `alt_image(img, first)` sets an image's own `fig-alt` as its description on any framed image, and Quarto's `alt` copy of a float's `fig-alt` only when `first` is set. `frame_para` sets `first` at the frame's first image that holds `alt`, through one `state` table per frame that `frame_first` creates and `frame_blocks` passes down, so an image in a caption (an icon in a top caption) does not count. A later image keeps its own `fig-alt` or its square-bracket text. The text goes in as one `pandoc.Str`, which keeps repeated spaces. `wrapped_image_docx` in `wrapped.lua` no longer copies `fig-alt` into an uncaptioned image's caption. Tests: six new cases in `tests/docx-alt.qmd` (fig-two, fig-two-first, fig-two-second, fig-two-icon, fig-spaced, a spaced uncaptioned image) and its snapshot. `docs/formats/word.qmd` and the DESIGN.md `wrapped-docx.lua` paragraph state the rule. The linked-image part of the source row moved to "Wrap images inside links in all formats".

**Decisions:** none milestone-local. D-018 (a float's `fig-alt` on the frame's first image only) records the user's question-set answer, added at review.
