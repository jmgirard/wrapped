# M011: Finish the figure width checks

**Status:** done (2026-10-27, PR #11 https://github.com/jmgirard/wrapped/pull/11)

**Goal:** A wrapped figure whose CSS function width is zero or below, or whose Typst width plus gap fills the text, takes the default width.

**Outcome:** Each calc parser function (`calc_args`, `calc_value`, `calc_product`, `calc_sum`, `calc_length`) also returns a bound: lower and upper sums of coefficients by unit, with absolute units in px, plus `exact` and `bad` (not finite) flags, built by `sum_add`, `bound_add`, `bound_scale`, `bound_number`, and `bound_pick` (min, max, and clamp as max of min). `never_positive` makes `checked_length` warn "zero, negative, or not finite" on a width whose upper sum is zero or below at every positive unit base, or that is not finite; `var()` leaves no bound, numbers are read as floats, and a quotient by a non-finite number has no bound. Typst: `wrapped-width(size, gap, ..widths)` with `wrapped-abs` returns the first width that fits with the gap, else 40%, and the first width on a page of auto width; `typst_fills` warns in `typst_open` (a figure's own percent width with a percent gap) and `read_meta` (a metadata percent width and gap) when the sum is 100% or more, naming 40% when the default with the gap fills too. Tests: 15 never-above-zero and 9 new passing values in css-functions.qmd; fixtures meta-calc-zero, typst-gap, typst-gap-meta, typst-gap-percent, typst-gap-default; 8 TYPST_LAYOUT cases and `typst_image_case`. 56 renders pass on macOS and in CI. README, DESIGN, and wrap-mechanisms updated.

**Decisions:** none milestone-local. Plan choices in the work log: a linear bound over sampling text widths; a Typst-side check in `layout` over a filter-side text width estimate. The question set chose a warning only when certain, and width plus gap at the text width with no minimum text column.
