# M029: Carry fig-alt to Word alt text

**Status:** done (2026-10-29, PR #31 https://github.com/jmgirard/wrapped/pull/31)

**Goal:** In Word output, each captioned figure that the extension puts in a Word frame has its `fig-alt` text as its image's alt text.

**Outcome:** In `wrapped-docx.lua`, `alt_image`, called from `frame_para` on every framed paragraph, sets each framed image's caption inlines (which Pandoc writes as `wp:docPr descr`) to its `fig-alt` attribute, else the `alt` that Quarto 1.10.19 copies from a float's `fig-alt` (a div float's image has only `alt`). The text replaces an existing description, such as a no-id image's caption, and an empty `fig-alt` gives empty alt text. Forms covered: markdown float, div float, inner-image class, captioned image with no id or a non-`fig-` id, knitr cell. Figures with no wrap class and wrapped figures that keep a normal figure in Word keep Quarto's alt text (D-017). Tests: new fixture `tests/docx-alt.qmd` (docx), its snapshot, and a `DOCX_UNFRAMED_ALT` section of `docx_summary` listing unframed images' alt text. `docs/formats/word.qmd` and the DESIGN.md `wrapped-docx.lua` paragraph state the rule.

**Decisions:** none milestone-local. D-017 (Word alt text only on framed figures) was added at plan from the user's question-set answer.
