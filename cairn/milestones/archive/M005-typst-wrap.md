# M005: Wrap figures in Typst PDF output

**Status:** done (2026-10-25, PR #5 https://github.com/jmgirard/wrapped/pull/5)

**Goal:** A document rendered to PDF through Typst with the extension installed shows body text beside each figure marked `.wrap-left` or `.wrap-right`.

**Outcome:** wrap-it 0.1.1 is bundled under `_extensions/wrapped/typst/packages/preview/` (D-004); Quarto stages it as the Typst package cache. The grouping pass writes each HTML group as raw Typst blocks that make one `#context wrap-content(align: top + wrapped-side(<side>), columns: wrapped-columns(<side>, <width>), column-gutter: <gap>, box(width: 100%)[figure], [paragraphs])` call. The width sets wrap-it's grid column (a percent on the box measured against its own column). Header helpers `wrapped-rtl`, `wrapped-side`, `wrapped-columns` keep sides physical in right-to-left text (from `text.dir` or Typst's right-to-left languages). A code cell keeps its code above the call. `typst_length` converts lengths (percent kept, px and unitless at 0.75 pt, pc at 12 pt, pt/mm/cm/in/em lowercased, others default with a warning); a percent of 100% or more and an image `height` warn; `format_default` serves LaTeX and Typst metadata. Context, next-block, and unplaced warnings print in Typst. Tests: Typst renders of fixture, defaults, stop-rule, contexts, and new typst-break, typst-ua, typst-rtl, typst-options (29 renders); the `.typ` summary records each call's options, box content and alt text, block kinds, citations, and unread calls. README gains a "PDF through Typst" section.

**Decisions:** none milestone-local. D-004 (bundle wrap-it) was added at plan. Implement choices are in the work log: raw blocks at `pre-quarto` over a `post-render` step, grid `columns:` for the width, and side helpers read in `context`.

**Review:** Plan criteria audit took 8 findings. Claim audits: 60 claims, 2 corrected (a Typst height was cut off at the box edge, now fixed); 41 claims, 3 corrected. Pass 1, four lenses, 24 findings: 16 fixed (return 1: right-to-left sides swapped; text lost at widths of 100% or more), 2 follow-up, 6 rejected. Pass 2, 25 findings: 8 fixed (summary block kinds, citations, alt text), 3 follow-up, 15 rejected. Follow-ups: new rows "Bound wide absolute widths in Typst", "Warn when a figure width is zero", "Check wrapped figures in Typst columns"; Typst notes added to "Handle a wrapped cell with two figures" and "Fall back in other margin and list forms". Hygiene graduated "Wrap figures in Typst PDF output", added one Known issue (Typst page-break gap), and captured three lessons.
