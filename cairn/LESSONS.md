# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-24 (M001, used M006): In a user Lua filter, `_quarto` is not defined and a plain `walk` does not see Quarto custom nodes such as `FloatRefTarget`. Handle the custom node at the filter's top level, and use `traverse = "topdown"` to carry state from an outer div to the figure inside it.
- 2026-10-24 (M001, used M005): Typst refuses a file path outside the document's folder ("would escape the project root"), so a Typst fixture keeps its images beside the `.qmd`.
- 2026-10-24 (M001): In a blobless (`--filter=blob:none`) quarto-cli clone, `git log -S` fetches every blob and ran about 40 minutes without finishing. To date a feature, read the file at each release tag with `git show <tag>:<path>` instead.
- 2026-10-25 (M002, used M007): A `FloatRefTarget` placed inside a new `pandoc.Div` vanishes from the output. Other passes see a float as a plain Div with `__quarto_custom_type` and `__quarto_custom_id` attributes, and the float handler reads that id through `float.__quarto_custom_node`, so match on the id instead of moving the float.
- 2026-10-25 (M002): In HTML, Quarto drops the classes, style, and attributes that a filter sets on a Pandoc `Figure` (a captioned image with no `#fig-` id). Put the Figure inside a Div of your own and style the Div.
- 2026-10-25 (M002): A float has no effect inside a CSS grid or flex item list. Quarto turns the page body into a grid when the page has margin content, and gives `.cell-output-display` `overflow-x: auto`. Wrap the float and its text in one `display: flow-root` div, and set that wrapper's overflow to visible.
- 2026-10-25 (M002, used M008): Quarto finds `_extensions/` only from the document's folder up to a project root, so a fixture in `tests/` needs a `tests/_extensions` symlink. On this Mac, knitr's default SVG device for Typst needs X11 libraries, so a Typst fixture sets `fig-format: png`.
- 2026-10-25 (M003): At `pre-quarto`, a plain walk sees callouts, tabsets, and floats as Divs with `__quarto_custom_type`. A float's own classes are not on that Div, but an edit to a plain node inside it lasts. To act on a float by its context, mark it by `__quarto_custom_id` in an earlier `Pandoc` pass, and read the mark in the float handler.
- 2026-10-25 (M003, used M007): A `Blocks` filter also runs on the block lists inside a code cell and a float, where a figure is the last block by design. For a rule about the next block, walk top-down and return `false` at cell and float Divs.
- 2026-10-25 (M003): revealjs caps every image at `max-width: 95%` and scales the slide. `getBoundingClientRect` reads scaled screen px, and computed styles read layout px, so a layout check on a slide converts one to the other.
- 2026-10-25 (M004, used M008): `tests/verify.py` renders `fixture.qmd` to LaTeX and then to Typst, and both write `tests/fixture.pdf`, so the PDF it leaves is Typst's. For LaTeX page images, run `quarto render fixture.qmd --to pdf` alone first. Quarto also deletes a `<name>.log` beside the `<name>.qmd` it renders, so send render output to another path.
- 2026-10-25 (M004, used M007): wrapfig places a waiting figure at the next paragraph start and sets the wrap with local assignments, so a paragraph inside a group (an unnumbered heading, a callout's end) loses the wrap when the group ends and later text runs over the figure. To see each placement, compile a copy of the kept `.tex` with `\usepackage[verbose]{wrapfig}` and read the log.
- 2026-10-25 (M004, used M007): `pdfinfo -struct` prints non-ASCII bytes, so `grep` treats its output as binary and prints nothing; use `grep -a`. In LaTeX, `\typeout` opens a group, so it reports `\currentgrouplevel` one too high; use `\message` to log a group level.
- 2026-10-25 (M005): wrap-it measures its fixed content in an auto grid column, so `box(width: 30%)` there resolves against that narrow column, not the text width. Set the width with wrap-it's `columns:` argument, where a percent is a share of the text width. wrap-it puts the grid in a `box`, which never breaks across pages, so a group that does not fit moves whole to the next page.
- 2026-10-25 (M005): Quarto 1.10 copies each extension's `typst/packages` to `.quarto/typst/packages` and passes it as `--package-cache-path`, so the user's Typst cache is not read. To prove the bundled copy loads, plant a marker in it, remove `.quarto/typst`, render, and look for the marker in the PDF text.
- 2026-10-25 (M005): Quarto's Typst template passes `lang` and drops `dir`. Typst sets right-to-left text from the language, but `text.dir` reads `auto` in `context`, so a direction check also tests `text.lang` against Typst's list (ar, dv, fa, he, ks, pa, ps, sd, ug, ur, yi). wrap-it's grid follows the text direction, so a physical side flips there.
- 2026-10-26 (M006): In docx, a raw `w:pPr` inline at a paragraph's start lands after Pandoc's own `w:pPr`, and Word 16 still reads a `w:framePr` and the last `w:pStyle` from it. But a raw inline beside a Pandoc `Figure`'s image makes Pandoc write the Figure as a one-cell table, so split the Figure into paragraphs first.
- 2026-10-26 (M006): Pandoc's default reference.docx has a body `w:sectPr` with no `w:pgSz` or `w:pgMar`. Word then shows a Letter page with 1 in margins (9360 twips of text), while Pandoc sizes percent images against 420 pt and caps them at 8400 twips. Set an image's width in inches to make it match a computed frame.
- 2026-10-26 (M006): Driving Word by AppleScript, an open or a save to a path Word's sandbox has not been granted shows a file-access prompt, and the call times out (-1712). Until the user allows it, `get name of every document` returns missing value. After the grant, save from the document that is already open.
- 2026-10-26 (M007): `pdftohtml -xml` gives each text line's and image's box at 1.5 px per pt, so it locates figures that `pdftotext -bbox` cannot. It writes image files beside its output path, so point that path into a temporary folder. In a wrapfig wrap, the first narrowed line sits above the image's top by \intextsep, so a "beside" test compares the line's bottom to the image's top.
- 2026-10-26 (M007): To learn whether a LaTeX layout fault predates a change, add `\vspace*{<n>\baselineskip}` to the base branch's kept `.tex` above the spot, compile it with lualatex for a range of n, and read the log for `Overfull \vbox`. In fixture.qmd a floating figure on the page of a knitr longtable overflows that page.
- 2026-10-26 (M007): wrapfig keeps `\WF@size` (the figure's depth plus 1.5 lines plus 2 \intextsep, less one \intextsep at a page top) global after it places a figure, and counts lines as floor((\WF@size + 1.1\baselineskip) / \baselineskip). A hook added to `\WF@startwrapping` with `\g@addto@macro` can log that count with `\message`.
- 2026-10-26 (M008): R's PNG device on Linux writes a 96-dpi pHYs tag and the macOS quartz device writes none, so Pandoc sizes an unsized knitr plot in docx differently on each system. A docx snapshot that records such a plot's width needs a set width for docx, such as `#| out-width: !expr if (knitr::pandoc_to("docx")) "5in"`. The cairo device fails on this Mac (no X11).
- 2026-10-26 (M008): In GitHub Actions, R, knitr, and rmarkdown from Ubuntu apt took 19 s to 36 min across runs; `r-lib/actions/setup-r` with `use-public-rspm: true` and `setup-r-dependencies` with `PKG_SYSREQS: false` took under a minute. A workflow triggered only by `schedule` or `workflow_dispatch` runs from the default branch, so a PR cannot run it.
