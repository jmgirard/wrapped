# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-24 (M001, used M022): In a user Lua filter, `_quarto` is not defined and a plain `walk` does not see Quarto custom nodes such as `FloatRefTarget`. Handle the custom node at the filter's top level, and use `traverse = "topdown"` to carry state from an outer div to the figure inside it.
- 2026-10-25 (M002, used M023): Quarto finds `_extensions/` only from the document's folder up to a project root, so a fixture in `tests/` needs a `tests/_extensions` symlink. On this Mac, knitr's default SVG device for Typst needs X11 libraries, so a Typst fixture sets `fig-format: png`.
- 2026-10-25 (M004, used M025): `tests/verify.py` renders `fixture.qmd` to LaTeX and then to Typst, and both write `tests/fixture.pdf`, so the PDF it leaves is Typst's. For LaTeX page images, run `quarto render fixture.qmd --to pdf` alone first. Quarto also deletes a `<name>.log` beside the `<name>.qmd` it renders, so send render output to another path.
- 2026-10-25 (M005, used M019): wrap-it measures its fixed content in an auto grid column, so `box(width: 30%)` there resolves against that narrow column, not the text width. Set the width with wrap-it's `columns:` argument, where a percent is a share of the text width. wrap-it puts the grid in a `box`, which never breaks across pages, so a group that does not fit moves whole to the next page.
- 2026-10-26 (M007, used M028): `pdftohtml -xml` gives each text line's and image's box at 1.5 px per pt, so it locates figures that `pdftotext -bbox` cannot. It writes image files beside its output path, so point that path into a temporary folder. In a wrapfig wrap, the first narrowed line sits above the image's top by \intextsep, so a "beside" test compares the line's bottom to the image's top.
- 2026-10-26 (M008, used M018): R's PNG device on Linux writes a 96-dpi pHYs tag and the macOS quartz device writes none, so Pandoc sizes an unsized knitr plot in docx differently on each system. A docx snapshot that records such a plot's width needs a set width for docx, such as `#| out-width: !expr if (knitr::pandoc_to("docx")) "5in"`. The cairo device fails on this Mac (no X11).
- 2026-10-27 (M010, used M026): Typst 0.15.1 has no function that prints a warning, so a check that runs in Typst can only fall back with no message. `layout(size => ...)` gives the text width as `size.width` and also gives context, so `text.dir` reads there. Quarto's `{{< pagebreak >}}` fails inside a `wrap-content` box ("pagebreaks are not allowed inside of containers").
- 2026-10-27 (M011, used M019): On a Typst page of auto width, `layout` gives an infinite `size.width` (`size.width.pt() == float.inf`). A ratio times a length is a length, and a percent `column-gutter` in wrap-it's grid is a share of the text width. A Typst fixture for a fallback width needs about 1 in of text beside the figure, or the marker words break one to a line and `find_words` finds no line.
- 2026-10-27 (M011, used M028): Lua 5.4's `tonumber` reads a digit string as an integer, so a sum or product past 2^63 wraps to a negative number; add `0.0` to read a CSS number as a float. `gh pr merge --delete-branch` also deletes the local branch, so tracking commits left unpushed there survive only in the reflog (`git log -g`).
- 2026-10-27 (M012, used M029): To check one fixture without the full `tests/verify.py` run, run from `tests/`: `python3 -c "import verify; code, log = verify.render('<name>', '<fmt>'); print(verify.summary('<name>', '<fmt>', log))"`. Writing that summary to `tests/_snapshots/<name>.<fmt>.txt` updates its snapshot. Right after `gh pr create`, `gh pr checks` printed "no checks reported" for about a minute before the PR's check appeared.
- 2026-10-27 (M013, used M029): Before a pre-quarto filter runs, Quarto copies a code cell's `cap-location` or `fig-cap-location` option onto the cell's float as its `cap-location` attribute, and `fig-column: X` or `column: X` reaches the cell as the class `fig-column-X` or `column-X`. To see what the filter sees, list a dump filter after `wrapped` with `at: pre-quarto` and print each `FloatRefTarget`'s classes and attributes.
- 2026-10-27 (M014, used M022): In a user filter's walk of a code cell, a float Div carries `__quarto_custom_type` but no float type, no `fig-` id, and a counter as `__quarto_custom_id`; `float.type` and the `<label>-1` id show only in the FloatRefTarget handler. A cell that draws two plots without `fig-subcap` makes two top-level floats; with `fig-subcap` it makes one float that holds a subfloat per plot.
- 2026-10-27 (M015, used M018): In Typst, Quarto 1.10.19 widens a page-wide div or code cell for all 16 classes (`#wideblock` or `#column-page-inset` and kin), but a float's own class, or a document `fig-column` on a float outside a cell, only for `column-page` and `column-screen` without `-inset`. A wrap box around a wideblock overlaps the text. A margin float becomes `#notefigure`, which `typ_summary` does not list.
- 2026-10-27 (M015, used M029): Before trusting where Quarto puts a figure, render a fixture copy with `filters:` removed and read its HTML classes and `.tex`/`.typ`. Quarto 1.10.19 applies a document `fig-column` even to a cell with `fig-column: body` and follows `cap-location` over `fig-cap-location`. knitr writes `#| classes: a b` as `{.cell .a b}`, so a second class needs its dot.
- 2026-10-28 (M017): Quarto 1.10.19's revealjs theme (`share/formats/revealjs/quarto.scss`) sets an aside to `position: absolute; bottom: 20px`, but to `initial` under `center: true` and `relative` on a `.scrollable` slide, and has no `column-margin` rule. In a bare revealjs render, a slide's lone image-form figure becomes an `r-stretch` `<img>` that carries the figure id, so look for the id on `img`.
- 2026-10-28 (M019): wrap-it's box holds only the text beside the figure; the rest flows below it, so a group moves to the next page or column only when the space left is less than the figure's height. With Typst `columns:`, `layout` gives the column (gutter 4% of the text), the title spans both columns, and pdftohtml's justified lines end 3 to 7 px past the column edge, so a layout check states widths as constants.
- 2026-10-28 (M020, used M028): In the built-in browser pane, a hidden page reads `window.innerWidth` as 0, so the 576px breakpoint applies and `tests/layout.js` reports every figure with `float: none`. Set a 1280x900 viewport and reload before `report()`, which returns `figures`, `groups`, and `images`, not an array. The `tests` entry of `.claude/launch.json` serves `tests/` on port 8791.
- 2026-10-28 (M021): Pandoc reads an HTML comment that opens a line as a RawBlock, so a paragraph cannot open with an inline comment; a test puts a leading comment in a span. Quarto 1.10.19 gives a shortcode block context only when it is its Para's one inline (`block_handler`), so a `meta` beside a comment or in a span renders as text. The merge guard denies `git merge --ff-only` on main; use `git pull --ff-only`.
- 2026-10-28 (M022, used M026): Quarto's dashboard filter runs after the filter (`quarto.doc.is_format("dashboard")` sees it), adds `html-fill-container` and `html-fill-item` to divs, so a cell's wrappers turn flex, and makes a cell outside a `.card` div its own card. The browser pane keeps a re-rendered page's old CSS: `await fetch(href, {cache: "reload"})`, then reload. It cannot script a `file://` page.
- 2026-10-28 (M023, used M027): knitr runs a ```{r} chunk even inside a four-backtick `markdown` fence of a `.qmd`; write ```{{r}} to show one. In a website page with both `pdf` and `typst` formats, both write `<name>.pdf`, so give `typst` its own `output-file`. `freeze: auto` hashes the whole `.qmd`, so a prose edit re-runs its cells. The filter warns as `(W) wrapped: …`, so a grep for "warn" misses it.
- 2026-10-28 (M025, used M028): In a hook on wrapfig's `\WF@startwrapping`, `\pagetotal` is current in the main vertical list, since `\WF@putfigmaybe` runs `\penalty\interlinepenalty` first, but stale inside a box. `\ReadonlyShipoutCounter` shows a page break since then. pdftohtml can split a sentence over two lines, so a layout check finds a one-word marker such as `zeta.`. A heading that does not fit with its next line starts the next page.
- 2026-10-28 (M026, used M028): pdftohtml reads a LibreOffice PDF of a docx with letters lost and added ("figrst"), so `tests/docs_layout.py` finds paragraphs by spacing and font, not words. `when-format="pdf"` matches LaTeX only, not Typst. wrapfig keeps one or two lines narrow past a figure's bottom. A prose edit to a frozen docs page needs a render with R before a no-R render passes.
- 2026-10-29 (M027, used M028): On the ubuntu-latest runner, inline code in a docs page's HTML sits more than 3 px lower than the text beside it, so a check that groups a paragraph's rects into lines joins a rect by its middle, not its top. Ubuntu 24.04's system pip refuses installs, so `docs.yml` puts Playwright in a venv under `$RUNNER_TEMP`. Test `tests/docs_layout.py` against a planted fault in a copy of `docs/_site` passed with `--site`.
- 2026-10-29 (M028): With `indent: true`, Quarto's LaTeX indents a first line 17 px and adds no paragraph gap. A LibreOffice PDF of a docx loses letters at a line's start, which moves the line 9 to 17 px right, so a PDF reader can read indents only in LaTeX and Typst. Playwright for Python is not on the Mac: run `--html` from a scratch venv with `pip install playwright==1.64.0`, whose Chromium is in `~/Library/Caches/ms-playwright`.
- 2026-10-29 (M029): At Word post-render, Quarto 1.10.19 puts a float's `fig-alt` on its image as `alt` (a div float's image has only `alt`), a captioned image with no `#fig-` id keeps only `fig-alt`, and Pandoc writes `wp:docPr descr` from the image's caption inlines, not from either attribute. Run `gh pr merge <N>` as a command of its own: the merge guard refuses it after a `cd … &&` with other commands beside it.
