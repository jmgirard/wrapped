# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-24 (M001, used M014): In a user Lua filter, `_quarto` is not defined and a plain `walk` does not see Quarto custom nodes such as `FloatRefTarget`. Handle the custom node at the filter's top level, and use `traverse = "topdown"` to carry state from an outer div to the figure inside it.
- 2026-10-25 (M002, used M015): Quarto finds `_extensions/` only from the document's folder up to a project root, so a fixture in `tests/` needs a `tests/_extensions` symlink. On this Mac, knitr's default SVG device for Typst needs X11 libraries, so a Typst fixture sets `fig-format: png`.
- 2026-10-25 (M003, used M014): A `Blocks` filter also runs on the block lists inside a code cell and a float, where a figure is the last block by design. For a rule about the next block, walk top-down and return `false` at cell and float Divs.
- 2026-10-25 (M004, used M009): `tests/verify.py` renders `fixture.qmd` to LaTeX and then to Typst, and both write `tests/fixture.pdf`, so the PDF it leaves is Typst's. For LaTeX page images, run `quarto render fixture.qmd --to pdf` alone first. Quarto also deletes a `<name>.log` beside the `<name>.qmd` it renders, so send render output to another path.
- 2026-10-25 (M004, used M009): wrapfig places a waiting figure at the next paragraph start and sets the wrap with local assignments, so a paragraph inside a group (an unnumbered heading, a callout's end) loses the wrap when the group ends and later text runs over the figure. To see each placement, compile a copy of the kept `.tex` with `\usepackage[verbose]{wrapfig}` and read the log.
- 2026-10-25 (M004, used M009): `pdfinfo -struct` prints non-ASCII bytes, so `grep` treats its output as binary and prints nothing; use `grep -a`. In LaTeX, `\typeout` opens a group, so it reports `\currentgrouplevel` one too high; use `\message` to log a group level.
- 2026-10-25 (M005, used M011): wrap-it measures its fixed content in an auto grid column, so `box(width: 30%)` there resolves against that narrow column, not the text width. Set the width with wrap-it's `columns:` argument, where a percent is a share of the text width. wrap-it puts the grid in a `box`, which never breaks across pages, so a group that does not fit moves whole to the next page.
- 2026-10-26 (M006, used M012): Pandoc's default reference.docx has a body `w:sectPr` with no `w:pgSz` or `w:pgMar`. Word then shows a Letter page with 1 in margins (9360 twips of text), while Pandoc sizes percent images against 420 pt and caps them at 8400 twips. Set an image's width in inches to make it match a computed frame.
- 2026-10-26 (M007, used M011): `pdftohtml -xml` gives each text line's and image's box at 1.5 px per pt, so it locates figures that `pdftotext -bbox` cannot. It writes image files beside its output path, so point that path into a temporary folder. In a wrapfig wrap, the first narrowed line sits above the image's top by \intextsep, so a "beside" test compares the line's bottom to the image's top.
- 2026-10-26 (M007): To learn whether a LaTeX layout fault predates a change, add `\vspace*{<n>\baselineskip}` to the base branch's kept `.tex` above the spot, compile it with lualatex for a range of n, and read the log for `Overfull \vbox`. In fixture.qmd a floating figure on the page of a knitr longtable overflows that page.
- 2026-10-26 (M007): wrapfig keeps `\WF@size` (the figure's depth plus 1.5 lines plus 2 \intextsep, less one \intextsep at a page top) global after it places a figure, and counts lines as floor((\WF@size + 1.1\baselineskip) / \baselineskip). A hook added to `\WF@startwrapping` with `\g@addto@macro` can log that count with `\message`.
- 2026-10-26 (M008): R's PNG device on Linux writes a 96-dpi pHYs tag and the macOS quartz device writes none, so Pandoc sizes an unsized knitr plot in docx differently on each system. A docx snapshot that records such a plot's width needs a set width for docx, such as `#| out-width: !expr if (knitr::pandoc_to("docx")) "5in"`. The cairo device fails on this Mac (no X11).
- 2026-10-26 (M009): Quarto shows no LaTeX package warning and deletes the `.log`; `latex-clean: false` keeps it beside the `.qmd`. TinyTeX sets `max_print_line` to 10000 and TeX Live to 79, and kpathsea reads it from the environment, so a log check renders with `max_print_line=79` and removes line breaks before it matches a warning.
- 2026-10-26 (M009): `\if@twocolumn` is set by `classoption`, a class default, `\twocolumn`, and paracol, and stays true inside `multicols` in two-column text, where multicol drops floats. An `env/multicols/begin` hook runs inside the environment's group. In a pdftohtml check of columns, a title spans both columns, and each marker sentence must fit one column line.
- 2026-10-26 (M008): In GitHub Actions, R, knitr, and rmarkdown from Ubuntu apt took 19 s to 36 min across runs; `r-lib/actions/setup-r` with `use-public-rspm: true` and `setup-r-dependencies` with `PKG_SYSREQS: false` took under a minute. A workflow triggered only by `schedule` or `workflow_dispatch` runs from the default branch, so a PR cannot run it.
- 2026-10-27 (M010, used M011): Typst 0.15.1 has no function that prints a warning, so a check that runs in Typst can only fall back with no message. `layout(size => ...)` gives the text width as `size.width` and also gives context, so `text.dir` reads there. Quarto's `{{< pagebreak >}}` fails inside a `wrap-content` box ("pagebreaks are not allowed inside of containers").
- 2026-10-27 (M010, used M012): Pandoc's smart punctuation runs on YAML metadata, so `var(--w)` in a metadata string reaches a filter with an en dash, and `2*1em*1` loses its asterisks to emphasis. `wrapped.lua` turns the en dash back into `--` after `pandoc.utils.stringify`, and the README asks for spaces around `*`.
- 2026-10-27 (M011): On a Typst page of auto width, `layout` gives an infinite `size.width` (`size.width.pt() == float.inf`). A ratio times a length is a length, and a percent `column-gutter` in wrap-it's grid is a share of the text width. A Typst fixture for a fallback width needs about 1 in of text beside the figure, or the marker words break one to a line and `find_words` finds no line.
- 2026-10-27 (M011, used M015): Lua 5.4's `tonumber` reads a digit string as an integer, so a sum or product past 2^63 wraps to a negative number; add `0.0` to read a CSS number as a float. `gh pr merge --delete-branch` also deletes the local branch, so tracking commits left unpushed there survive only in the reflog (`git log -g`).
- 2026-10-27 (M012, used M016): To check one fixture without the full `tests/verify.py` run, run from `tests/`: `python3 -c "import verify; code, log = verify.render('<name>', '<fmt>'); print(verify.summary('<name>', '<fmt>', log))"`. Writing that summary to `tests/_snapshots/<name>.<fmt>.txt` updates its snapshot. Right after `gh pr create`, `gh pr checks` printed "no checks reported" for about a minute before the PR's check appeared.
- 2026-10-27 (M013, used M016): Before a pre-quarto filter runs, Quarto copies a code cell's `cap-location` or `fig-cap-location` option onto the cell's float as its `cap-location` attribute, and `fig-column: X` or `column: X` reaches the cell as the class `fig-column-X` or `column-X`. To see what the filter sees, list a dump filter after `wrapped` with `at: pre-quarto` and print each `FloatRefTarget`'s classes and attributes.
- 2026-10-27 (M014): In a user filter's walk of a code cell, a float Div carries `__quarto_custom_type` but no float type, no `fig-` id, and a counter as `__quarto_custom_id`; `float.type` and the `<label>-1` id show only in the FloatRefTarget handler. A cell that draws two plots without `fig-subcap` makes two top-level floats; with `fig-subcap` it makes one float that holds a subfloat per plot.
- 2026-10-27 (M015, used M016): In Typst, Quarto 1.10.19 widens a page-wide div or code cell for all 16 classes (`#wideblock` or `#column-page-inset` and kin), but a float's own class, or a document `fig-column` on a float outside a cell, only for `column-page` and `column-screen` without `-inset`. A wrap box around a wideblock overlaps the text. A margin float becomes `#notefigure`, which `typ_summary` does not list.
- 2026-10-27 (M015, used M016): Before trusting where Quarto puts a figure, render a fixture copy with `filters:` removed and read its HTML classes and `.tex`/`.typ`. Quarto 1.10.19 applies a document `fig-column` even to a cell with `fig-column: body` and follows `cap-location` over `fig-cap-location`. knitr writes `#| classes: a b` as `{.cell .a b}`, so a second class needs its dot.
- 2026-10-28 (M016): In PDF, Quarto 1.10.19 places a code cell's figure by the document's `fig-column`, else its `column`, over the cell's own option, and at pre-quarto a knitr cell's float carries none of the cell's column classes. A layout panel under a document `fig-column: page` is `figure*` in LaTeX but a plain `#figure` in Typst. A bare HTML render spreads column classes over figure, image, and container, so read HTML places in a browser.
