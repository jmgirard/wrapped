# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).

- 2026-10-25 (M002, used M038): Quarto finds `_extensions/` only from the document's folder up to a project root, so a fixture in `tests/` needs a `tests/_extensions` symlink. On this Mac, knitr's default SVG device for Typst needs X11 libraries, so a Typst fixture sets `fig-format: png`.
- 2026-10-25 (M004, used M040): `tests/verify.py` renders `fixture.qmd` to LaTeX and then to Typst, and both write `tests/fixture.pdf`, so the PDF it leaves is Typst's. For LaTeX page images, run `quarto render fixture.qmd --to pdf` alone first. Quarto also deletes a `<name>.log` beside the `<name>.qmd` it renders, so send render output to another path.
- 2026-10-26 (M007, used M040): `pdftohtml -xml` gives each text line's and image's box at 1.5 px per pt, so it locates figures that `pdftotext -bbox` cannot. It writes image files beside its output path, so point that path into a temporary folder. In a wrapfig wrap, the first narrowed line sits above the image's top by \intextsep, so a "beside" test compares the line's bottom to the image's top.
- 2026-10-27 (M011, used M040): Lua 5.4's `tonumber` reads a digit string as an integer, so a sum or product past 2^63 wraps to a negative number; add `0.0` to read a CSS number as a float. `gh pr merge --delete-branch` also deletes the local branch, so tracking commits left unpushed there survive only in the reflog (`git log -g`).
- 2026-10-27 (M012, used M040): To check one fixture without the full `tests/verify.py` run, run from `tests/`: `python3 -c "import verify; code, log = verify.render('<name>', '<fmt>'); print(verify.summary('<name>', '<fmt>', log))"`. Writing that summary to `tests/_snapshots/<name>.<fmt>.txt` updates its snapshot. Right after `gh pr create`, `gh pr checks` printed "no checks reported" for about a minute before the PR's check appeared.
- 2026-10-27 (M013, used M038): Before a pre-quarto filter runs, Quarto copies a code cell's `cap-location` or `fig-cap-location` option onto the cell's float as its `cap-location` attribute, and `fig-column: X` or `column: X` reaches the cell as the class `fig-column-X` or `column-X`. To see what the filter sees, list a dump filter after `wrapped` with `at: pre-quarto` and print each `FloatRefTarget`'s classes and attributes.
- 2026-10-27 (M015, used M040): Before trusting where Quarto puts a figure, render a fixture copy with `filters:` removed and read its HTML classes and `.tex`/`.typ`. Quarto 1.10.19 applies a document `fig-column` even to a cell with `fig-column: body` and follows `cap-location` over `fig-cap-location`. knitr writes `#| classes: a b` as `{.cell .a b}`, so a second class needs its dot.
- 2026-10-28 (M020, used M038): In the built-in browser pane, a hidden page reads `window.innerWidth` as 0, so the 576px breakpoint applies and `tests/layout.js` reports every figure with `float: none`. Set a 1280x900 viewport and reload before `report()`, which returns `figures`, `groups`, and `images`, not an array. The `tests` entry of `.claude/launch.json` serves `tests/` on port 8791.
- 2026-10-28 (M023, used M040): knitr runs a ```{r} chunk even inside a four-backtick `markdown` fence of a `.qmd`; write ```{{r}} to show one. In a website page with both `pdf` and `typst` formats, both write `<name>.pdf`, so give `typst` its own `output-file`. `freeze: auto` hashes the whole `.qmd`, so a prose edit re-runs its cells. The filter warns as `(W) wrapped: …`, so a grep for "warn" misses it.
- 2026-10-28 (M025, used M037): In a hook on wrapfig's `\WF@startwrapping`, `\pagetotal` is current in the main vertical list, since `\WF@putfigmaybe` runs `\penalty\interlinepenalty` first, but stale inside a box. `\ReadonlyShipoutCounter` shows a page break since then. pdftohtml can split a sentence over two lines, so a layout check finds a one-word marker such as `zeta.`. A heading that does not fit with its next line starts the next page.
- 2026-10-28 (M026, used M039): pdftohtml reads a LibreOffice PDF of a docx with letters lost and added ("figrst"), so `tests/docs_layout.py` finds paragraphs by spacing and font, not words. `when-format="pdf"` matches LaTeX only, not Typst. wrapfig keeps one or two lines narrow past a figure's bottom. A prose edit to a frozen docs page needs a render with R before a no-R render passes.
- 2026-10-29 (M027, used M028): On the ubuntu-latest runner, inline code in a docs page's HTML sits more than 3 px lower than the text beside it, so a check that groups a paragraph's rects into lines joins a rect by its middle, not its top. Ubuntu 24.04's system pip refuses installs, so `docs.yml` puts Playwright in a venv under `$RUNNER_TEMP`. Test `tests/docs_layout.py` against a planted fault in a copy of `docs/_site` passed with `--site`.
- 2026-10-29 (M028): With `indent: true`, Quarto's LaTeX indents a first line 17 px and adds no paragraph gap. A LibreOffice PDF of a docx loses letters at a line's start, which moves the line 9 to 17 px right, so a PDF reader can read indents only in LaTeX and Typst. Playwright for Python is not on the Mac: run `--html` from a scratch venv with `pip install playwright==1.64.0`, whose Chromium is in `~/Library/Caches/ms-playwright`.
- 2026-10-29 (M029, used M040): At Word post-render, Quarto 1.10.19 puts a float's `fig-alt` on its image as `alt` (a div float's image has only `alt`), a captioned image with no `#fig-` id keeps only `fig-alt`, and Pandoc writes `wp:docPr descr` from the image's caption inlines, not from either attribute. Run `gh pr merge <N>` as a command of its own: the merge guard refuses it after a `cd … &&` with other commands beside it.
- 2026-10-29 (M030): At Word post-render, Quarto 1.10.19 puts a div float's `fig-alt` as `alt` on every image in its body, own `fig-alt` or not, and on no image in its caption. A lone captioned image in a div float becomes a Pandoc Figure, so its text shows twice in Word, filter or not. Pandoc reads a line break in a quoted attribute as a space. `tests/` has no `note.png`; the docx-alt snapshot's `note.png` is Quarto's callout icon.
- 2026-10-29 (M031, used M033): Quarto 1.10.19 makes `[![cap](x.png)](url)` a Figure, or a float with a `#fig-` id, but leaves `[![](x.png)](url)` a Para that holds a Link. In the filter's Lua, a change to an element read from a list, such as `link.content[1].classes`, reaches the list. A snapshot counts equal warnings once, so each test case gets its own image file. LibreOffice's PDF of a docx drops image links, filter or not.
- 2026-10-29 (M032, used M036): The Bash tool's shell is zsh, which does not split an unquoted `$p`, so `for p in "twocolumn pdf"; do set -- $p` left `$2` empty and wrote `tests/_snapshots/twocolumn pdf..txt`. Loop over fixtures inside the Python one-liner instead. A Link handler in the filter's last pass sees links in the title metadata, captions, and footnotes, each once.
- 2026-10-29 (M033, used M040): Quarto 1.10.19 applies a pipe table's caption block, `: Cap {.wrap-left}`, in `table_classes()` after pre-quarto filters, so the filter sees a classless Table whose caption ends so. A `#tbl-` div's or knitr `tbl-cap`'s block is text too, in `float.caption_long.content`; only `{#tbl-x}` reaches the float earlier (corrected M034). Jupyter: scratch venv with `jupyter matplotlib`, `QUARTO_PYTHON=<venv>/bin/python`.
- 2026-10-29 (M034, used M040): Pandoc's LaTeX and Word writers keep a Space at a caption's end, which HTML hides, so a caption rewrite is checked in the `.tex`. Quarto's own caption-block parse strips that Space only while the block is there to read. `quarto render --output-dir <dir>` from `tests/` adds `/.quarto/` lines to `tests/.gitignore`; revert them. pandoc Lua's `pairs(attr.attributes)` keeps source order.
- 2026-10-30 (M035, used M040): To test an old Quarto, unpack its `quarto-<v>-macos.tar.gz` release asset in a scratch folder and run `tests/verify.py` with its `bin` first on `PATH`. The `quarto-<v>` generator tag in `tests/fixture.html` confirms the version. quarto-actions/setup takes a bare version such as `1.9.36`, and a matrix renames the check to `verify (<entry>)`. A freeze hash is the md5 of the page source.
- 2026-10-30 (M036, used M040): In Typst, Quarto 1.10.19 writes a margin float as `#notefigure(` with `kind:` on its first line and its label after the closing `)`, a margin float with no caption as a body `#figure(`, and an aside figure as `#note(` around a `#figure(`. The CI `verify` checks take 8 to 9 minutes, longer than one 590 s `gh pr checks --watch` call, so the first wait after `gh pr create` can time out.
- 2026-10-30 (M038, used M040): In a pre-quarto filter a FloatRefTarget's `float.content` can be one Block, and `Block:walk` skips its root, so walk `pandoc.Blocks({ content })`. Quarto copies a code cell's classes and its `tbl-cap-location` to the cell's table float; a knitr table cell's `column-page` sits on the `cell-output-display` div inside the float. `pkill -f` on a command also kills a `( a; b ) &` chain that names it.
- 2026-10-31 (M039): Pandoc 3.10's docx writer writes a raw openxml block as it is, unbalanced tags included, so a post-render filter can open a `w:tbl` in one raw block and close it in another around native blocks. Pandoc then puts nothing between that raw table and a table before it, which Word joins, nor the `w:p` that must end a `w:tc`. gt and flextable write a Word table as one raw openxml block.
- 2026-10-31 (M040): A filter that `pandoc.write`s part of the document at pre-quarto works before Quarto's shortcodes, cross-references, and citeproc, and outside the main template, so a citation in it prints as text and `\st` or `\VERB` is undefined. Write a token for each piece, then splice the original inlines or blocks back between RawInlines, and Quarto and the main writer process them.
